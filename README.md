# 📅 WP Bookfa — Next-Gen WordPress Appointment Booking Plugin

[![WordPress Version](https://img.shields.io/badge/WordPress-6.5%2B-blue.svg)](https://wordpress.org)
[![PHP Version](https://img.shields.io/badge/PHP-8.1%2B-777BB4.svg)](https://php.net)
[![License](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)

یک افزونه فوق‌العاده مدرن، سریع و ایجکسی (SPA) برای رزرو آنلاین جلسات، مشاوره و زمان‌بندی کاری مدرسین در وردپرس.  
این افزونه با معماری پاک و شیءگرا، فرآیند رزرو وقت را بدون رفرش صفحه و در نهایت سادگی برای کاربران فراهم می‌کند.

---

## ✨ ویژگی‌های کلیدی

- ⚡ **معماری REST API Native:** تعاملات تماماً ایجکسی و بدون رفرش صفحه بر پایه استاندارد WP REST API
- 🎨 **طراحی مدرن و واکنش‌گرا (UI/UX 2026):** رابط کاربری ۴ مرحله‌ای گام‌به‌گام، مینیمال و شیک توسعه‌یافته با Tailwind CSS
- 🗄️ **دیتابیس اختصاصی و بهینه:** استفاده از جداول مجزای دیتابیس برای جلوگیری از کندی و سنگین شدن جدول `wp_postmeta`
- 🔒 **سیستم هوشمند جلوگیری از رزرو همزمان (Anti-Double Booking):** قفل‌گذاری روی سانس‌ها جهت جلوگیری از تداخل زمان‌بندی‌ها
- 👥 **مدیریت سطح دسترسی و مدرسین (Role-Based Access):**
    - **مدیر کل:** دسترسی کامل به تنظیم شیفت کاری و مشاهده رزروهای تمامی مدرسین
    - **مدرسین:** پنل اختصاصی جهت تعریف شیفت‌ها و مدیریت زمان‌بندی‌های شخصی
- 📊 **پنل مدیریت اختصاصی:** رابط کاربری مجزا در پیشخوان وردپرس با امکان تغییر شیفت‌ها و مشاهده لیست رزروها همراه با فیلتر هوشمند

- **PHP:** نسخه ۸.۱ یا بالاتر

## 🚀 نصب و راه‌اندازی

1. پوشه افزونه را در مسیر `wp-content/plugins/wp-bookfa` قرار دهید.
2. افزونه را از بخش **افزونه‌ها** در پیشخوان وردپرس فعال کنید.
3. یک‌بار به مسیر **تنظیمات ⬅️ پیوندهای یکتا** رفته و روی **ذخیره تغییرات** کلیک کنید تا قوانین REST API بازنشانی شوند.

---
