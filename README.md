# WP Bookfa - WordPress Appointment Booking Plugin

یک افزونه مدرن، ایجکسی (SPA-like) و بسیار سریع برای رزرو وقت آنلاین مدرسین و مشاورین در وردپرس.

## ویژگی‌ها

- **REST API Native**: عملکرد کاملاً بدون رفرش بر پایه وردپرس ۷+
- **طراحی مدرن ۲۰۲۶**: UI رزرو چندهنگامه گام‌به‌گام بر پایه Tailwind CSS
- **جداول اختصاصی DB**: جداول سبک مجزا جهت جلوگیری از سنگین شدن `wp_postmeta`
- **جلوگیری از Double Booking**: ساختار محافظت از ثبت رزروهای همزمان

## نحوه استفاده

شورت‌کد زیر را در هر برگه یا پست وردپرس قرار دهید:
`[wp_bookfa]`
